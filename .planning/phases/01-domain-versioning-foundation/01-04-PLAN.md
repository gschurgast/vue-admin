Créer `api/src/EventListener/TransformationHashListener.php` suivant **strictement** le Pattern 6 du RESEARCH + le cas DELETE (Pitfall C). Pattern à recopier : `api/src/EventListener/ProductVariantDefaultListener.php`.

```php
<?php
namespace App\EventListener;

use App\Entity\AssetTransformation\AssetTransformation;
use App\Entity\AssetTransformation\TransformationStep;
use App\Message\PurgeTransformationVariantsMessage;
use App\Service\AssetTransformation\TransformationHasher;
use Doctrine\Bundle\DoctrineBundle\Attribute\AsDoctrineListener;
use Doctrine\ORM\Event\OnFlushEventArgs;
use Doctrine\ORM\Events;
use Symfony\Component\Messenger\MessageBusInterface;

#[AsDoctrineListener(event: Events::onFlush)]
#[AsDoctrineListener(event: Events::postFlush)]
final class TransformationHashListener
{
    /** @var list<PurgeTransformationVariantsMessage> */
    private array $pendingPurges = [];

    public function __construct(
        private readonly TransformationHasher $hasher,
        private readonly MessageBusInterface $bus,
    ) {}

    public function onFlush(OnFlushEventArgs $args): void
    {
        $em   = $args->getObjectManager();
        $uow  = $em->getUnitOfWork();
        $meta = $em->getClassMetadata(AssetTransformation::class);

        /** @var array<int, AssetTransformation> $dirty — dedup by id (Pitfall G) */
        $dirty = [];

        // 1. Step insertions/updates/deletions bubble up to their parent transformation
        foreach ([
            ...$uow->getScheduledEntityInsertions(),
            ...$uow->getScheduledEntityUpdates(),
            ...$uow->getScheduledEntityDeletions(),
        ] as $entity) {
            if ($entity instanceof TransformationStep) {
                $parent = $entity->getTransformation();
                if ($parent !== null) {
                    // Parent may not have an id yet if it's also being inserted in this flush;
                    // dedup by spl_object_id in that case so we still recompute its hash.
                    $key = $parent->getId() ?? -spl_object_id($parent);
                    $dirty[$key] = $parent;
                }
            }
        }

        // 2. AssetTransformation direct insertions/updates
        foreach ([
            ...$uow->getScheduledEntityInsertions(),
            ...$uow->getScheduledEntityUpdates(),
        ] as $entity) {
            if ($entity instanceof AssetTransformation) {
                $key = $entity->getId() ?? -spl_object_id($entity);
                $dirty[$key] = $entity;
            }
        }

        // 3. Recompute hash for each dirty transformation
        foreach ($dirty as $transformation) {
            $oldHash = $transformation->getVersionHash();
            $newHash = $this->hasher->compute($transformation);
            if ($newHash === $oldHash) {
                continue;
            }
            $transformation->setVersionHash($newHash);
            // Tell Doctrine the entity changed mid-flush so it includes versionHash in the UPDATE
            $uow->recomputeSingleEntityChangeSet($meta, $transformation);

            // Queue purge of OLD hash variants (skip on creation — oldHash is null)
            if ($oldHash !== null && $transformation->getId() !== null) {
                $this->pendingPurges[] = new PurgeTransformationVariantsMessage(
                    $transformation->getId(),
                    $oldHash,
                );
            }
        }

        // 4. Special case: AssetTransformation being deleted — capture hash BEFORE row vanishes
        foreach ($uow->getScheduledEntityDeletions() as $entity) {
            if ($entity instanceof AssetTransformation
                && $entity->getId() !== null
                && $entity->getVersionHash() !== null
            ) {
                $this->pendingPurges[] = new PurgeTransformationVariantsMessage(
                    $entity->getId(),
                    $entity->getVersionHash(),
                );
            }
        }
    }

    public function postFlush(): void
    {
        foreach ($this->pendingPurges as $msg) {
            $this->bus->dispatch($msg);
        }
        $this->pendingPurges = [];
    }
}
```

**Points clés à respecter** :
- **Pitfall A** : itérer Insertions + Updates + Deletions, pas juste Updates
- **Pitfall B** : dispatch UNIQUEMENT dans `postFlush()`, pas dans `onFlush()`
- **Pitfall C** : capture du versionHash de l'entité supprimée AVANT flush (l'entité est encore en mémoire dans onFlush)
- **Pitfall G** : dédup par id (ou spl_object_id pour les entités sans id encore)
- **Pitfall D** déjà adressé en Plan 01 : versionHash absent du group `:write`

Pas de configuration `services.yaml` nécessaire : l'attribut `#[AsDoctrineListener]` + autowire/autoconfigure activé (config existante du projet) suffit.

<?php
namespace App\Tests\Integration\EventListener;

use App\Entity\AssetTransformation\AssetTransformation;
use App\Entity\AssetTransformation\TransformationStep;
use App\Enum\StepType;
use App\Message\PurgeTransformationVariantsMessage;
use Doctrine\ORM\EntityManagerInterface;
use Symfony\Bundle\FrameworkBundle\Test\KernelTestCase;
use Symfony\Component\Messenger\Transport\InMemoryTransport;

final class TransformationHashListenerTest extends KernelTestCase
{
    private EntityManagerInterface $em;
    private InMemoryTransport $transport;

    protected function setUp(): void
    {
        self::bootKernel(['environment' => 'test']);
        $this->em = self::getContainer()->get(EntityManagerInterface::class);

        // Recreate schema for an isolated test DB
        $tool = new \Doctrine\ORM\Tools\SchemaTool($this->em);
        $metas = $this->em->getMetadataFactory()->getAllMetadata();
        $tool->dropSchema($metas);
        $tool->createSchema($metas);

        $this->transport = self::getContainer()->get('messenger.transport.transformations_backfill');
        $this->transport->reset();
    }

    public function testCreateTransformationComputesHash(): void
    {
        $t = new AssetTransformation();
        $t->setCode('test-create')->setLabel('Test create');
        $s = new TransformationStep();
        $s->setType(StepType::RESIZE)->setParams(['width' => 800])->setPosition(0);
        $t->addStep($s);

        $this->em->persist($t);
        $this->em->flush();

        self::assertNotNull($t->getVersionHash());
        self::assertSame(40, strlen($t->getVersionHash()));
        // No purge dispatched on creation (oldHash was null)
        self::assertCount(0, $this->transport->getSent());
    }

    public function testAddingStepRecomputesHashAndDispatchesPurge(): void
    {
        $t = new AssetTransformation();
        $t->setCode('test-add-step')->setLabel('Test');
        $s1 = (new TransformationStep())->setType(StepType::RESIZE)->setParams(['width' => 800])->setPosition(0);
        $t->addStep($s1);
        $this->em->persist($t);
        $this->em->flush();
        $originalHash = $t->getVersionHash();
        $this->transport->reset();

        // Add a second step
        $s2 = (new TransformationStep())->setType(StepType::FORMAT_CONVERT)->setParams(['format' => 'webp'])->setPosition(1);
        $t->addStep($s2);
        $this->em->flush();

        self::assertNotSame($originalHash, $t->getVersionHash());
        $envelopes = $this->transport->getSent();
        self::assertCount(1, $envelopes);
        $msg = $envelopes[0]->getMessage();
        self::assertInstanceOf(PurgeTransformationVariantsMessage::class, $msg);
        self::assertSame($t->getId(), $msg->transformationId);
        self::assertSame($originalHash, $msg->versionHash);
    }

    public function testRemovingStepRecomputesHash(): void
    {
        $t = new AssetTransformation();
        $t->setCode('test-rm-step')->setLabel('Test');
        $s = (new TransformationStep())->setType(StepType::ROTATE)->setParams(['angle' => 90])->setPosition(0);
        $t->addStep($s);
        $this->em->persist($t);
        $this->em->flush();
        $hashWithStep = $t->getVersionHash();

        $t->removeStep($s);
        $this->em->flush();

        self::assertNotSame($hashWithStep, $t->getVersionHash());
    }

    public function testDeletingTransformationDispatchesPurge(): void
    {
        $t = new AssetTransformation();
        $t->setCode('test-delete')->setLabel('To delete');
        $s = (new TransformationStep())->setType(StepType::RESIZE)->setParams([])->setPosition(0);
        $t->addStep($s);
        $this->em->persist($t);
        $this->em->flush();
        $hashBeforeDelete = $t->getVersionHash();
        $idBeforeDelete = $t->getId();
        $this->transport->reset();

        $this->em->remove($t);
        $this->em->flush();

        $envelopes = $this->transport->getSent();
        self::assertCount(1, $envelopes);
        $msg = $envelopes[0]->getMessage();
        self::assertSame($idBeforeDelete, $msg->transformationId);
        self::assertSame($hashBeforeDelete, $msg->versionHash);
    }

    public function testNoOpUpdateProducesNoPurge(): void
    {
        $t = new AssetTransformation();
        $t->setCode('test-noop')->setLabel('Orig');
        $s = (new TransformationStep())->setType(StepType::RESIZE)->setParams(['width' => 800])->setPosition(0);
        $t->addStep($s);
        $this->em->persist($t);
        $this->em->flush();
        $hashBefore = $t->getVersionHash();
        $this->transport->reset();

        // Change only label — steps unchanged → hash unchanged → no purge
        $t->setLabel('Updated label');
        $this->em->flush();

        self::assertSame($hashBefore, $t->getVersionHash());
        self::assertCount(0, $this->transport->getSent());
    }
}

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04-01 | Tampering | versionHash écrit par autre chose que le listener | mitigate | versionHash absent du group `:write` (Plan 01) ; setter `@internal` documenté. Le test `testNoOpUpdateProducesNoPurge` prouve l'idempotence |
| T-01-04-02 | DoS | Flush récursive (Pitfall B) si dispatch en onFlush | mitigate | Dispatch déféré en postFlush via `$pendingPurges[]` — pattern verifié par tests d'intégration. Mémoire bornée par la durée d'une seule flush |
| T-01-04-03 | Repudiation | Hash recomputed deux fois sur la même transformation (label + step modifiés en même flush) | mitigate | Dédup par id dans `$dirty` map (Pitfall G). Test à ajouter si concernant — pour Phase 1, l'idempotence du hasher rend ça inoffensif |
| T-01-04-04 | Information disclosure | Message Messenger sérialisé contient le versionHash | accept | Le hash n'est pas un secret (publié dans les URLs S3 / cache). Pas de PII |
| T-01-04-05 | Denial of service | Files Redis Streams accumulent sans consumer en Phase 1 | accept | Volume Phase 1 négligeable (modifications admin manuelles). Worker provisionné en Phase 7 (OPS-04). Documenté dans le SUMMARY |
| T-01-04-06 | Elevation of privilege | Handler stub no-op masque une vraie exécution malveillante | accept | Phase 1 par design. Phase 3+ ajoutera la purge S3 réelle avec sa propre threat model (path traversal, prefix escape) |
