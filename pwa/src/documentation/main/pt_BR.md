# Bem-vindo ao WebfactoAdmin

Este aplicativo permite que você gerencie seus recursos de forma eficiente.
Use o menu de navegação à esquerda para alternar entre diferentes recursos.

## Navegação

Use a barra lateral para navegar entre recursos. Você pode recolher a barra lateral para ter mais espaço.

## Pesquisa

Pressione **⌘K** (Mac) ou **Ctrl+K** (Windows/Linux) ou clique no ícone de pesquisa para abrir a paleta de comandos.
Você pode pesquisar recursos e navegar rapidamente.

## Gerenciar Itens

- **Criar:** Clique no botão + na barra superior.
- **Editar:** Clique no ícone do lápis em um item.
- **Excluir:** Clique no ícone da lixeira em um item.
