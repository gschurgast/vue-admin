# WebfactoAdmin へようこそ

このアプリケーションでは、リソースを効率的に管理できます。
左側のナビゲーションメニューを使用して、異なるリソース間を切り替えます。

## ナビゲーション

サイドバーを使用してリソース間を移動します。サイドバーを折りたたんでスペースを広げることができます。

## 検索

**⌘K**（Mac）または **Ctrl+K**（Windows/Linux）を押すか、検索アイコンをクリックしてコマンドパレットを開きます。
リソースを検索して素早く移動できます。

## アイテムの管理

- **作成：** 上部バーの + ボタンをクリックします。
- **編集：** アイテムの鉛筆アイコンをクリックします。
- **削除：** アイテムのゴミ箱アイコンをクリックします。
