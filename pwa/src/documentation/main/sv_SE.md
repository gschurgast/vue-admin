# Välkommen till WebfactoAdmin

Denna applikation låter dig hantera dina resurser effektivt.
Använd navigeringsmenyn till vänster för att växla mellan olika resurser.

## Navigering

Använd sidofältet för att navigera mellan resurser. Du kan dölja sidofältet för att få mer utrymme.

## Sök

Tryck på **⌘K** (Mac) eller **Ctrl+K** (Windows/Linux) eller klicka på sökikonen för att öppna kommandopaletten.
Du kan söka efter resurser och navigera snabbt.

## Hantera objekt

- **Skapa:** Klicka på + knappen i det övre fältet.
- **Redigera:** Klicka på pennikonen på ett objekt.
- **Ta bort:** Klicka på papperskorgsikonen på ett objekt.
