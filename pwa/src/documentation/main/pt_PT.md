# Bem-vindo ao WebfactoAdmin

Esta aplicação permite-lhe gerir os seus recursos de forma eficiente.
Use o menu de navegação à esquerda para alternar entre diferentes recursos.

## Navegação

Use a barra lateral para navegar entre recursos. Pode recolher a barra lateral para ter mais espaço.

## Pesquisa

Prima **⌘K** (Mac) ou **Ctrl+K** (Windows/Linux) ou clique no ícone de pesquisa para abrir a paleta de comandos.
Pode pesquisar recursos e navegar rapidamente.

## Gerir Itens

- **Criar:** Clique no botão + na barra superior.
- **Editar:** Clique no ícone do lápis num item.
- **Eliminar:** Clique no ícone do caixote do lixo num item.
